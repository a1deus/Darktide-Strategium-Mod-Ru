# Strategium — русский перевод

`strategium_ru` добавляет русский перевод мода Strategium для **Warhammer 40,000: Darktide**. Strategium выводит службы «Траурной звезды» на экран выбора персонажа, откуда можно открыть доску заданий, начать быструю игру или зайти в Псайканум.

## Что переведено

- Названия и описания служб «Траурной звезды», кнопки и подсказки на экране выбора персонажа.
- Меню быстрой игры и «Водоворота», статусы поиска, таймеры событий и подсказки о наградах.
- Интерфейс ударного отряда и подписи чата.
- Настройки Strategium в меню модов, варианты компоновки и редактор тем.

## Требования

- [Darktide Mod Loader](https://www.nexusmods.com/warhammer40kdarktide/mods/19) и [Darktide Mod Framework (DMF)](https://www.nexusmods.com/warhammer40kdarktide/mods/8).
- [Strategium](https://www.nexusmods.com/warhammer40kdarktide/mods/1536) от HereticEater, установленный отдельно. Ориентир для версии перевода `1.0.0` — Strategium `1.4.1`.
- Русский язык интерфейса Darktide.

## Установка

1. Установите Darktide Mod Loader, DMF и Strategium, если они ещё не установлены. [Руководство по установке модов](https://github.com/Darktide-Mod-Framework/Darktide-Mod-Framework/wiki/Installing-mods).
2. Скачайте и распакуйте архив перевода. Если скачали **Source code (zip)** из GitHub Releases, переименуйте распакованную папку в `strategium_ru`.
3. Поместите папку `strategium_ru` в папку `mods` игры. Проверьте, что файл мода находится по пути `mods/strategium_ru/strategium_ru.mod`.
4. В файле `mods/mod_load_order.txt` добавьте `strategium_ru` строкой **выше** `strategium`:

   ```text
   strategium_ru
   strategium
   ```

5. Запустите игру с русским языком интерфейса. Если игра уже открыта, перезапустите её.

## Если часть текста осталась на английском

Проверьте язык игры и порядок загрузки. После обновления Strategium новые или изменённые строки могут остаться на английском до обновления перевода. Если в Strategium появится собственный перевод строки, игра будет использовать его.

Об ошибках перевода можно сообщить во вкладке **Issues**. Укажите версии перевода и Strategium и приложите скриншот или напишите, где встретилась строка.
